# Plan And Design Template

**Category**: template

## Purpose

Complete template design including purpose, parameters, steps, and flow diagram

## Substeps

  0. Review requirements
  1. Check existing templates
  2. Write purpose statement
  3. Define use cases
  4. Check existing reusable steps
  5. Plan step breakdown
  6. Identify parameters
  7. Design process flow
  8. Create mermaid diagram
  9. End-Step: Compliance Check
